# Calculator Pintar (Premium Web Calculator)

Aplikasi kalkulator berbasis web sederhana dengan desain premium (Glassmorphism) dan fitur efek suara digital terintegrasi menggunakan Web Audio API.

## Fitur
- Desain antarmuka modern yang estetik.
- Logika kalkulator lengkap (Tambah, Kurang, Kali, Bagi).
- Fitur suara (Audio Beep) interaktif untuk setiap tombol.
- Tidak membutuhkan koneksi internet atau library eksternal saat dijalankan (Vanilla HTML/CSS/JS).

## Cara Menjalankan (Instalasi)

Karena aplikasi ini murni dibangun menggunakan HTML, CSS, dan JavaScript tanpa framework tambahan, Anda tidak perlu menginstal `Node.js`, `NPM`, atau software server apapun!

### Langkah-langkah:

1. **Clone Repositori Ini**
   Buka terminal/Command Prompt dan jalankan perintah berikut:
   ```bash
   git clone https://github.com/satriogph-boop/Calculator-Pintar.git
   ```
   *(Atau Anda bisa mengklik tombol hijau **"Code"** di halaman GitHub ini lalu memilih **"Download ZIP"**, kemudian ekstrak file ZIP tersebut).*

2. **Buka Folder Proyek**
   Masuk ke dalam folder `Calculator-Pintar` yang baru saja Anda download/clone.

3. **Jalankan di Browser**
   Cari file bernama `index.html`. Klik dua kali (*double-click*) pada file tersebut. Kalkulator akan langsung terbuka dan siap digunakan di browser favorit Anda (Chrome, Edge, Firefox, dll)!

---
*Catatan: Pastikan speaker/volume komputer Anda menyala untuk mendengarkan efek suara saat menekan tombol kalkulator.*
