# Calculator Pintar

Aplikasi kalkulator berbasis web dengan desain modern, riwayat perhitungan, dukungan keyboard, tema gelap/terang, dan efek suara digital menggunakan Web Audio API.

## Fitur

- Operasi dasar: tambah, kurang, kali, dan bagi.
- Riwayat perhitungan yang tersimpan di browser.
- Dukungan keyboard untuk angka, operator, `Enter`, `Backspace`, dan `Escape`.
- Mode tema gelap dan terang.
- Efek suara interaktif untuk tombol kalkulator.
- Dibangun dengan HTML, CSS, JavaScript, dan Vite.

## Instalasi

Pastikan sudah menginstal [Node.js](https://nodejs.org/), lalu jalankan:

```bash
git clone https://github.com/satriogph-boop/Calculator-Pintar.git
cd Calculator-Pintar
npm install
```

## Menjalankan Project

Untuk menjalankan aplikasi saat development:

```bash
npm run dev
```

Setelah itu buka URL yang muncul di terminal, biasanya:

```text
http://127.0.0.1:5173
```

## Build

Untuk membuat versi production:

```bash
npm run build
```

Untuk melihat hasil build secara lokal:

```bash
npm run preview
```
